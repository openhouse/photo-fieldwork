# Roadmap

## 0.2: preserve the successful production path

- Whole-library source profile and frozen membership digest.
- Append-only run events and derived status.
- Per-view evaluation and uncertainty gates.
- Provenance-aware safety review.
- Fresh inspection deltas.
- Content-addressed plans, immutable attempts, and topology verification.

## 0.3: make runs easier to operate

- One orchestration command with resumable phase checkpoints.
- Generated local status and gap report.
- Decision templates and preflight command.
- Artifact-schema validation at every CLI boundary.

## 0.4: improve local editorial review

- Static local run companion linking contact sheets, decisions, evals, holds,
  plans, attempts, and verification.
- Confidence intervals and configurable stratified sample policies.
- Publication-readiness review kept separate from editor-field membership.

## 0.5: broaden trustworthy adapters

- Fake-catalog integration suite with interruption and retry simulation.
- Portable filesystem reference adapter.
- Explicit Apple Photos compatibility and migration policy.
- Large-inventory benchmarks and checkpointed retrieval.

## 1.0 boundary

A new operator can complete and resume the full source-freeze, retrieval,
inspection, evaluation, safety review, write-test, production, idempotence, and
independent-verification path without editing code or reconstructing state by
hand.
