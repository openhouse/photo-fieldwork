# Residency studio: a bounded first response

The residency dream belongs partly to Photo Fieldwork and partly to the social,
editorial, and institutional life around it. Photo Fieldwork should support the
private source-to-studio boundary well. It should not try to become the whole
residency, a collaborative archive platform, or an automated authority over
context and publication.

## Corrected current state

The helper authorization blocker described in the July 22 reflection is now
historical. The merged helper repair established a stable app-bundle canary,
nonce-bound receipt waiting, explicit removable-volume handling, maximal
private metadata capability reporting, typed PhotoKit collection identifiers,
and an independently verified one-photo catalog write.

## Added now

`photo-fieldwork studio` adds the smallest useful exploratory layer between
retrieval and formal evaluation. It is a static private light table built from
verified local previews. Residents can change density, move through adjacent
frames, pin a comparison, take a deterministic chance walk, make temporary
piles, distinguish four kinds of notes, and leave images uncertain or for
later. Browser-local state resumes when the exact studio is reopened, and a
private notebook export records the encounter without claiming evaluation or
publication.

This covers several immediate desires without changing Photos or adding a
server, account, database, sync system, or public route.

## Already supported elsewhere

- Broad private reading is provided by the inventory, osxphotos, ExifTool, and
  PhotoKit capability layers.
- Reproducible fields and evaluation samples preserve how an image surfaced.
- Membership-only plans provide narrow studio-album writes with receipts,
  idempotence checks, and independent verification.
- Publication projection remains default-closed and destination-specific.

## Worth learning through a real encounter

- which context fields residents actually consult while looking;
- whether side-by-side pinning is enough for sequences or a larger sequence
  bench is warranted;
- whether piles should remain free labels or become ordered sequences;
- which counter-searches produce discovery rather than novelty;
- how residents want to exchange notebook observations with Jamie without
  turning private exploration into a shared surveillance surface.

## Deliberately deferred

- visual-similarity or semantic-vector search;
- multi-user synchronization and permissions;
- a private Knowledge Wiki integration;
- automated rights, consent, relationship, or factual-context decisions;
- any edit to originals, metadata, People, dates, locations, favorites, or
  prior residency versions.

These may become appropriate after a bounded fifty-image encounter reveals a
repeated need. They are not prerequisites for beginning to look.
