# Design principles

## Looking is not retrieval

Metadata can make a photograph available for attention. It cannot establish visible fit.

## Visible fit is not provenance

An image can look related to a project without proving who made, led, hosted, or authorized the work.

## Provenance is not consent

Knowing who, where, and when does not establish permission to publish.

## Absence is information

An empty project view, an unclassified field, and a protected HOLD are legitimate findings. Do not pad a category to avoid discomfort.

## Evaluation changes the system

A failed sample is useful when its errors alter retrieval, selection, safety, or labels. Metrics without inspected failures are decoration.

## Mutation stays narrow

Plans precede writes. Writes create folders and albums and add existing membership only. Verification is independent and read-only.

## Completion is derived

A run is complete only when every required phase has a passing, checksummed receipt. A sentence in a report cannot substitute for evidence.
